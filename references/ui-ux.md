# UI/UX Reference

Build production UI, not a static mock.

- Mobile-first responsive behavior.
- Semantic HTML and accessible labels.
- Keyboard focus and at least 44x44px touch targets.
- Loading, empty, error, disabled, hover, pressed, and success states.
- Consistent typography, spacing, hierarchy, and design tokens.
- Respect reduced motion and contrast requirements.
- Use reference images/Figma as visual guidance; implement actual responsive behavior rather than describing it.
- Avoid generic template repetition and unnecessary visual effects.
