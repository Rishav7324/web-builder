# SEO & Performance Reference

For public pages implement unique metadata, canonical URLs, Open Graph data, semantic headings, internal links, image alt text, structured data when appropriate, sitemap, robots rules, and noindex for private/admin/draft routes.

For performance use responsive images, lazy loading where useful, code splitting, server rendering/caching when beneficial, pagination, debounced search, indexed queries, avoidance of N+1 queries, optimized fonts, and minimal client JavaScript.
