## Documentation navigation rule

When a reference contains a version-sensitive API, first inspect the project's installed version and then open the corresponding official documentation. Prefer primary vendor/framework docs and standards. If an official page redirects or has moved, search the same official domain rather than substituting an unofficial mirror. Keep legal/regulatory research separate from implementation assumptions and flag material uncertainty for human/legal review.
