# Additional Agent Adapters

Instruction-tier adapters are provided for Kiro, Qoder, OpenClaw, Devin, Grok, JetBrains Junie, Amp, Jules, Zed, Aider, CodeWhale, Swival, and generic Agent Skills hosts.

Native rule/skill paths live at the repository root. The common behavior is always `skills/web-builder/SKILL.md`; adapters never fork the core workflow.
